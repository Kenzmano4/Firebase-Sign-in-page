# Project Overview
This project features a user-friendly authentication interface, including both Sign In and Sign Up pages designed for a smooth user experience.

## Sign In Page
The Sign In page includes input fields for email and password, along with clickable Google and Facebook icons that allow users to authenticate via their social media accounts. Additionally, there is a link that directs new users to the Sign Up page.

![Website sign in](<Img/sign in.JPG>)

## Sign Up Page
The Sign Up page serves as a registration form and closely resembles the Sign In page. However, it includes additional input fields for capturing the user's first and last name, enabling a more detailed user profile setup.
